# backie

Небольшая утилита для инкрементального резервного копирования каталогов.

`backie` сравнивает SHA-256 хеши файлов в источнике с хешами, сохранёнными в
манифесте предыдущего запуска, и копирует только изменившиеся или новые файлы.
Неизменившиеся файлы пропускаются.

## Использование

```sh
backie -s <SOURCE> -t <TARGET>
```

- `-s, --source` — каталог-источник, который нужно забэкапить.
- `-t, --target` — каталог-назначение, куда будут скопированы файлы.

Пример:

```sh
backie -s ~/projects/notes -t /backup/notes
```

## Как это работает

1. Утилита рекурсивно обходит каталог-источник и для каждого файла вычисляет
   SHA-256 хеш.
2. Считывает манифест из `<TARGET>/manifest.json`, если он есть.
3. Если манифест есть — копирует только файлы, у которых хеш изменился или
   которых нет в манифесте.
4. Если манифеста нет (первый запуск) — очищает каталог-назначение и копирует
   все файлы из источника.
5. Атомарно записывает обновлённый манифест в `<TARGET>/manifest.json`.

## Безопасность

- `source` и `target` не могут указывать на один и тот же каталог — утилита
  откажется работать, чтобы случайно не уничтожить исходные данные при первом
  запуске.
- `source` должен существовать и быть директорией.
- Манифест записывается атомарно через временный файл `manifest.json.tmp` с
  последующим `rename`, поэтому полупустой JSON на диске невозможен даже при
  килле процесса посреди записи.
- Если при старте обнаружен остаточный `manifest.json.tmp` от прерванного
  прогона, он удаляется.

## Сборка

```sh
cargo build --release
```

Бинарник появится в `target/release/backie`.

## Зависимости

- `clap` — разбор аргументов командной строки.
- `sha2` — вычисление SHA-256.
- `hex` — кодирование хешей в hex-строку для манифеста.
- `serde_json` — чтение и запись манифеста.
- `colour` — цветной вывод в консоль.
